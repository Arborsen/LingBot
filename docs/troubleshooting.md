# 环境与评测排错记录

| 问题 | 检查方法与处理方向 | 现有记录入口 |
| --- | --- | --- |
| 深度模块安装牵动训练依赖版本 | 对照固定依赖，检查 pip check 和导入；当前 MoGe 安装采用 --no-deps，需要先满足依赖 | [环境脚本](../lingbot-vla-v2/tools/create_train_env.sh) |
| 模型或归一化文件路径失效 | 检查机器人配置、模型位置、输出目录与 Conda 路径；历史绝对路径不能直接用于另一台机器 | [复现指南](reproduction.md) |
| 评测设置混淆 | 同时核对 task_config、instruction_type 和训练数据；保留旧诊断实验，不合并不同设置 | [实验索引](../experiments/README.md) |
| 进度计数与完成任务数不一致 | 进度可能包含运行中任务的视频；成功率按已验证任务计算，结束状态检查 results.json | [归档工具](../tools/archive_experiments.py) |
| 录制视频缺少仿真帧 | 当前仿真源码有逐步写入 RGB 帧的个人修改；准备上游修复时需要独立验证录制模式和输出时序 | [贡献清单](../contributions/README.md) |

后续遇到新问题，在这里或独立笔记中补充错误信息、根因、具体修改和验证结果；一次安装成功或单样本通过不代表整套训练评测已验证。
